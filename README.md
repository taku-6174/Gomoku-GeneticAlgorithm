## プロジェクト概要

**「五目並べ AI を自作し、遺伝的アルゴリズム（Genetic Algorithm; GA）で自動的に強化する」**ことを目的とした研究・実装プロジェクトです。  
PyGame によるインタラクティブな盤面表示と、対戦結果・進化履歴の可視化を通して、**ゲーム AI の設計とメタヒューリスティクス（GA）によるパラメータ最適化**を一体的に体験できるようにしています。

本プロジェクトは、**九州大学芸術工学部メディアデザインコース（三年次編入）への出願ポートフォリオ**として制作しています。

## 目標

- **初期状態の五目並べ AI（手作業で設計した評価関数）よりも明らかに強い「進化個体」を作ること**
- 五目並べが理論上「先手必勝」とされる性質を踏まえ、
  - **先手番ではほぼ負けない（限りなく勝ちに近い）AI**
  - **後手番でも簡単には負けない AI**
  を目指してパラメータを最適化すること
- その過程を通じて、**評価関数の設計・探索アルゴリズム・GA の設計**を統合的にデザインし、メディアデザインとしてもわかりやすく可視化・提示すること

## アプローチ概要

- **ゲームエンジン（`engine.py`）**
  - クラス `GomokuAnalyzer` が 15×15 の五目並べを管理
  - 連・活四・眠四・活三・フォーク（33, 43, 44）などの**パターンベース評価関数**を実装
  - αβ枝刈り付きミニマックス探索＋候補手の絞り込みにより、実用的な思考時間で最善手を探索

- **インタラクティブな AI 解析ツール（`main.py`）**
  - PyGame で盤面を描画し、
    - 人間 vs AI
    - AI vs AI（同一個体）
    - AI vs 人間（AI 先手）
    - 異なる重みを持つ AI 同士（進化個体 vs 別個体）
    といったモードで対戦可能
  - 各マスに「その手の評価値」を色と数字で重ねて表示し、**AI がどの手をどれくらい高く評価しているかを視覚的に理解できる**ようにしている

- **遺伝的アルゴリズムによる重み最適化（`ga_manager.py`）**
  - 個体 = `GomokuAnalyzer` の**評価関数の重みセット**
  - 各個体同士や基準個体との多数対局を並列に行い、**勝率を fitness として評価**
  - トーナメント選択・交叉・突然変異により世代を重ね、世代ごとの **best / average / worst fitness を記録・グラフ化**（`evolution_graph.png`）
  - 最良個体の重みは `best_weights.txt` として保存し、GUI や別スクリプトから再利用可能

- **進化前後の比較評価（`evaluate_evolution.py`）**
  - 初期個体（デフォルト重み）と進化個体（`best_weights.txt`）を多数対局させ、
    - 先手時の勝率
    - 後手時の勝率
    - 引き分け率
    を統計的に比較する。

## このプロジェクトで示したいこと

- ゲームルールの理解から、
  - **評価関数の設計**
  - **探索アルゴリズム（ミニマックス＋αβ枝刈り）**
  - **遺伝的アルゴリズムによるパラメータ最適化**
  - **インタラクティブな可視化 UI のデザイン**
  までを一貫して自分で設計・実装していること。
- 「AI が何を考えて打っているのか？」を、単なるブラックボックスではなく、**視覚的・インタラクティブに体験できるメディア作品**として提示していること。
- 完全解（先手必勝戦略）までは到達していないものの、**初期 AI よりも明確に強いプレイスタイルが GA によって自動的に獲得されていくプロセス**を、データとビジュアルでわかりやすく示していること。

## 環境・実行方法（メモ）

- Python 3.12 以降
- 主要ライブラリ：
  - `pygame`
  - `numpy`
  - `matplotlib`
  - `numba`（高速評価関数用、任意）

### ローカル実行例

- GUI で AI の思考を可視化しながら対局：

```bash
python main.py
```

- 遺伝的アルゴリズムで評価関数の重みを進化させる：

```bash
python ga_manager.py
```

- 進化個体と初期個体を大量対局させて勝率を評価：

```bash
python evaluate_evolution.py
```

（環境構築や依存パッケージは、必要に応じて今後追記予定）
